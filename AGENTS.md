# Projet CéPAGRAVE

- Utiliser le profil Chrome `Cepagrave` et le compte GitHub `Cpasgrave` pour ce projet.
- Hébergement : GitHub Pages, dépôt `Cpasgrave/cpasgrave.github.io`, branche `main`, dossier publié `dist/`. Adresse : `https://cpasgrave.github.io/`.
- Avant toute opération sur un service Google, vérifier dans ce profil l’adresse du compte Google connecté et son association au projet. Ne pas utiliser une session Google différente par défaut.
- Les fichiers de `dist/` sont les sources éditables de ce site statique. Garder l’avatar d’origine et l’archive du jeu Quarto intacts ; faire les adaptations dans la copie locale séparée.
